## 🔍 我的拆解方法

我基于 **MDA 框架**（机制 → 动态 → 体验）拆解游戏，核心是回答四个问题：

1. **为什么这么设计**（设计目的）
2. **怎么设计的**（规则与数值）
3. **带给了玩家什么体验**
4. **哪里可以做得更好**（改进建议）

在广度速览中，每款游戏按「拉新 / 留存 / 运营 / 机制 / 付费」五维 + 核心循环 + 可优化点结构化呈现；在深度拆解中，进一步拆到玩家分层、资源流向、数值规律与商业化机制。
