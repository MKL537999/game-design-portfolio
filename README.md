## 🔍 我的拆解方法

每款游戏我都从五个问题出发：

1. **拉新** —— 它如何吸引新玩家？
2. **留存** —— 它如何留住老玩家？
3. **运营** —— 它如何做长线运营？
4. **机制** —— 玩法机制有什么亮点？
5. **付费** —— 靠什么吸引玩家投入金钱？
